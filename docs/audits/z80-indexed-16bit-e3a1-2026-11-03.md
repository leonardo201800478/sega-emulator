# E3A1 — Operações 16-bit do Z80 com IX/IY

**Baseline:** abd154332b1dabfb68874f2b80f306da7e060552  
**Escopo desta fatia:** LD IX/IY,nn; INC/DEC IX/IY; ADD IX/IY,BC/DE/IX|IY/SP; JP (IX/IY); LD SP,IX/IY.

## Arquitetura

- Reutiliza os handlers BASE e os pares de registradores compartilhados; o par 2 resolve HL quando não há prefixo e IX/IY quando o latch E2 está ativo.
- Mantém o estado de prefixo durante leituras imediatas e ciclos internos, inclusive snapshots restauráveis.
- Preserva o contador M-cycle acumulado pelos M1 DD/FD; os ciclos internos 2T/7T avançam a partir desse offset, inclusive em cadeias repetidas.
- Não altera o caminho BASE sem prefixo.
- Famílias de transferência absoluta, PUSH/POP e EX (SP),IX/IY permanecem para a fatia seguinte.

## Semântica

- INC/DEC IX/IY não alteram flags.
- ADD IX/IY,rr preserva S/Z/PV, atualiza H/C, limpa N e deriva X/Y do byte alto do resultado; WZ recebe o destino antigo + 1, seguindo o helper BASE existente.
- LD IX/IY,nn usa duas leituras imediatas little-endian.
- WAIT estende os ciclos de leitura sem alterar a ordem dos requests.

## Testes

Inclui vetores de IX/IY, last-prefix-wins, wrap de 16 bits, flags, WZ, WAIT, snapshot em ciclo interno e rejeição explícita de família ainda não implementada.

**Limites:** não declara cobertura total E3, diferencial independente, LONG_PASS ou TEMPORAL_PASS.
