## 1. Regras permanentes

Siga integralmente as instruções permanentes do projeto Sega Emulator (versão 2.1, 03/11/2026) presentes no contexto do projeto. Em especial:

- Runtime de hardware 100% Rust; Python/PySide6 somente GUI, launcher, configurações, logs, telemetria e automação; PyO3 coarse-grained.
- Componentes compartilhados com implementação única; não duplicar Z80, ALU, barramentos ou chips por console.
- MachineScheduler governa clocks/eventos. Exigir causalidade determinística, WAIT real, operações suspensíveis/retomáveis e equivalência entre execução contínua e em blocos.
- Não usar JIT, frame skipping, hacks de timing ou otimizações especulativas.
- GitHub é a fonte da verdade. Nunca commitar diretamente na main, usar force-push ou reset destrutivo.
- Toda alteração não trivial em branch e PR. Nunca fazer merge com CI vermelho, pendente ou não correspondente ao HEAD final.
- Não declarar teste, aprovação, ciclo ou comportamento sem evidência reproduzível.

Gates obrigatórios:
```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
python -m pytest
python -m ruff check .
python -m ruff format --check .
```
Registrar também Windows x64 D3D12/vídeo, WASAPI/XAudio2/áudio e Scheduler deterministic stress. SKIPPED não é PASS. Classificar cada suíte PASS/FAIL/BLOCKED/NOT RUN.
