# Sega Emulator v0.1.0 — primeiro release SG-1000

**Status:** candidato em validação; notas ainda em rascunho. Não publicar antes da validação manual no Windows e da aprovação do SHA final.

## Destaques

- Primeiro pacote público planejado para o marco SG-1000.
- Integração da máquina com CPU Z80, memória/I/O, VDP TMS9918A, PSG SN76489AN e entrada.
- Frontend Qt/PySide6 com saída de áudio PCM via WASAPI compartilhado e apresentação Qt Quick com Vulkan solicitado e fallback raster.
- Modo imersivo de tela cheia para exibir somente o jogo, com F11/Alt+Enter para alternar e Esc para retornar.
- Diálogo Sobre com versão, escopo, créditos tecnológicos, licença MIT e aviso de projeto independente.
- Diagnósticos de sessão, snapshots de VDP e captura de writes do PSG em VGM para investigação.

## Requisitos e instalação

- Windows x64.
- Python 3.14.x x64.
- Instale o frontend Qt com os extras do projeto:
  ```powershell
  python -m pip install -e ".[dev,qt,frontend]"
  python -m sega_emulator
  ```
- A extensão nativa Rust/PyO3 precisa ser construída em Release conforme as instruções do README se não estiver instalada no ambiente.

## Limitações importantes

- A avaliação de áudio e vídeo é observacional. O áudio foi considerado muito próximo ao Gearsystem em teste manual, mas não há certificação de equivalência com hardware original.
- Pequenos engasgos e possível deriva de sincronismo em sessões prolongadas ainda precisam ser investigados.
- O modelo de CPU usa T-states nominais por instrução; não alegamos temporização ciclo a ciclo de barramento.
- Vulkan é solicitado ao Qt Quick, com fallback raster. A API efetivamente ativa depende da máquina e deve ser confirmada nos logs.
- Compatibilidade universal com ROMs e revisões de hardware não é garantida.
- O crate standalone `native/sg1000_core` permanece parcial; não confundir com a máquina integrada usada pela aplicação.
- Use ROMs homebrew ou cópias obtidas legalmente. ROMs comerciais, BIOS e dumps protegidos não são distribuídos.

## Licença e créditos

Distribuído sob a licença MIT; consulte o arquivo `LICENSE`. Projeto independente, sem afiliação oficial à SEGA. SEGA e SG-1000 são marcas de seus respectivos titulares. Créditos tecnológicos incluem Rust, Python, Qt for Python (PySide6), PyO3, SDL3 e PortAudio/sounddevice.
