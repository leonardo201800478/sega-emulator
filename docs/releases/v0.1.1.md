# Sega Emulator v0.1.1 — sessão de áudio Rust-only

**Status:** atualização em validação; não é uma declaração de release final nem de migração completa.

## Alterações

- Move a sessão DSP/resampler para native/audio_runtime, independente de PyO3 e Python.
- Introduz PcmSink para separar processamento PCM de backends host e permitir testes determinísticos sem dispositivo de áudio.
- Adapta WASAPI Shared/IAudioClient3 e XAudio2 como sinks nativos Rust.
- Remove da API PyO3 as operações de drenagem de amostras/PCM e escrita PCM, além dos wrappers de resampler e saída.
- Remove as fachadas Python de resampling e encaminhamento PCM.
- Migra os testes do pipeline para Rust, incluindo geração PSG e comparação determinística SG-1000/SMS com sink em memória.
- Atualiza a versão do pacote Python de 0.1.0 para 0.1.1.

## Limitações e pendências

- A sessão é executada em Rust, mas o pump ainda ocorre ao final de run_frame(), cuja chamada é disparada pelo pacing Qt. Scheduler e produção de áudio independentes do timer continuam pendentes.
- WASAPI/XAudio2 físicos, hotplug, sessões longas e latência ponta a ponta ainda precisam de validação no Windows.
- O mixer integrado continua usando a fonte PSG mono atualmente disponível; FM/YM2413, fontes estéreo nativas e filtros analógicos calibrados por chip não são declarados implementados.
- A temporização do hardware continua baseada nos modelos atuais; esta versão não declara precisão ciclo a ciclo.

## Critérios de validação

- cargo fmt, cargo clippy e cargo test dos crates audio_runtime e z80_core no SHA candidato.
- Build Release/Maturin e testes de integração do frontend após remoção das APIs antigas.
- Evidência Windows física separada para WASAPI/XAudio2 e latência.
