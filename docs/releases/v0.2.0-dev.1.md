## Escopo desta versão

Esta versão formaliza e versiona o baseline SMS que já está integrado à `main`:

- BIOS SMS opcional de 8 KiB mapeada integralmente em `$0000-$1FFF`.
- Seleção de família de BIOS por preferência manual, cabeçalho TMR SEGA e DAT exato, com política conservadora para conflito/ambiguidade.
- DATs distribuídos com o pacote.
- Resolução regional determinística, incluindo Brazil/PAL-M.
- Integração Rust, PyO3, Python e Qt.

A PR de versionamento não reaplica nem duplica a correção de BIOS já integrada pela PR #292.

## O que esta versão NÃO entrega

- SRAM de cartucho e persistência de saves no mapper Sega padrão.
- Mapper Codemasters.
- Mappers Korean/MSX/Nemesis/Janggun ou multicarts.
- Correção comprovada do boot de 128 Hap.
- Compatibilidade geral de ROMs, validação LONG_PASS ou TEMPORAL_PASS.

Essas lacunas permanecem explícitas no roadmap `docs/architecture/sms-cartridge-mapper-roadmap.md`.
