# Z80 ED Opcode Matrix — 256 encodings

**Main consultada:** `c2dae949d24b6a41899b0335ae2dd7f35b89ef26` (após squash da PR #729 de reconciliação documental F-015; sem alteração do runtime ED).
**Profile alvo:** Zilog NMOS Z80 usado pelos sistemas Sega atuais. O núcleo não expõe seletor NMOS/CMOS; CMOS não está implementado nem validado.
**Corpus externo:** SingleStepTests/Z80 revision `ebe1875d48f374bcfd4b505d8eb8ee751568b5f7` foi integrado para F-037, não para a família ED nesta etapa.

## Escopo e interpretação

A matriz enumera todos os 256 segundos bytes após o prefixo ED. O decoder possui 78 codificações explicitamente tratadas; os 178 bytes restantes seguem o perfil de compatibilidade reservado descrito nesta auditoria. A classificação usa UM0080, a tabela MAME fixada abaixo e referências secundárias; MAME é evidência de implementação, não prova de silício.

Após o merge da PR #706, o braço residual de `execute_ed_register_control` no microsequenciador chama `retire(opcode)` depois dos dois M1 já consumidos. Isso aposenta o opcode em 8T nominais, sem ciclos internos artificiais nem transações adicionais. O executor atômico permanece um caminho distinto e não deve ser confundido com a validação temporal do microsequenciador.

- **UM0080:** documenta as instruções ED oficiais. A tabela IN r,(C) marca r=110 como encoding indefinido que atualiza flags; a tabela OUT (C),r não inclui r=110; IM 0/1/2 são ED46/ED56/ED5E; NEG/RETN/RETI são ED44/ED45/ED4D.
- **MAME:** `z80.lst`, commit `c7541016a35d83a3eb5db5db5d20a5cb79a17a43`, usa `illegal_2()` nos 178 bytes reservados e documenta aliases.
- **CMOS:** não suportado pelo projeto. Diferenças citadas em fontes secundárias são registradas como incerteza, não como comportamento implementado.
- **Validação retomável:** `ed_reserved_f033.rs` percorre os 178 bytes reservados no microsequenciador; cobre estado arquitetural, WAIT e snapshot/restore. Os testes atômicos não substituem essa evidência temporal.
