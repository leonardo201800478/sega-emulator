
 This is the SMS port of a Sega Genesis program which dumps the V counter
 in several different display modes, and allows the user to browse through
 the results.

 You can have the program read 262 or 312 lines, this is dependant if the
 hardware is NTSC or PAL. Otherwise you'll just read the V counter wrapping
 again (312 lines for NTSC) or you'll cut off some of the results (262
 lines for PAL)
