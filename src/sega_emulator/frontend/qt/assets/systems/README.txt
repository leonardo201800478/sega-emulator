Sega Emulator console artwork assets
====================================
Six transparent PNG cutouts intended for the system selector cards.
These assets replace only the six console illustrations; do not replace
background.svg, splash_hero.svg, or change the UI layout when integrating.

Files: sg1000.png, master_system.png, game_gear.png, mega_drive.png,
sega_cd.png, 32x.png

Note: artwork was AI-generated. Review labels and hardware details before
treating the images as historically exact product photography.
